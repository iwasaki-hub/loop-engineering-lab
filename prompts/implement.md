docs/spec.mdとAGENTS.mdを読み、ヘルスチェックAPIを実装してください。

1. 既存ファイルと差分を確認し、要件を整理する。
2. npm.cmd testを実行し、実装前の失敗原因を確認する。
3. src/app.jsとsrc/server.jsを設計書に従って実装する。
4. npm.cmd run checkとnpm.cmd testを実行する。
5. 失敗したらログから原因を分析し、修正して再検証する。修正は最大3サイクル。
6. npm.cmd startで起動し、GET /healthを確認後、自分が起動したプロセスを終了する。
7. docs/loop-log.mdに実際のコマンド、結果、修正理由、未解決事項を記録する。

要件やテストの期待値を勝手に変更しないでください。
最終報告には要件ごとの対応状況と検証結果を含めてください。
