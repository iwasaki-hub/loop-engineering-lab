# 開発事例の挿絵

2026-11-03、imagegenスキルと組み込みImage Generationツールで4点を生成。Sharpで900×600のWebP（品質82）へ変換し、client/src/assets/illustrations/に保存。実行時依存の追加なし。生成原本はCodexのgenerated_imagesに保持。

各本文のテーマを緑・オレンジ・アイボリーの紙とクレイ風イラストで表現。ページでは左右交互、760px以下では画像・本文の順。遅延読み込み・寸法・代替テキストを設定。
